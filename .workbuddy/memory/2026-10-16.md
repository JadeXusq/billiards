# 2026-10-16

## 上午：修复「人机模式只有台面、无球、AI 不动作」

用户反馈截图：HUD 正常、绿呢画出来了，但台面上一颗球都没有、无法开始。

### 根因（两个 bug，均在客户端渲染/逻辑，服务端与物理单测覆盖不到）
1. **`renderer.js` 漏 import `POCKET_R`**：袋口循环用到但未从 constants 引入 → `ReferenceError`，在画完台面后、画球前抛出 → rAF 循环首帧即死 → 只剩台面、HUD 停在默认文案。
2. **球对象两种形状不统一**：离线物理球用 `type/number/active`，而 `game.js`/`ai.js`/`renderer.js` 按在线快照形状读 `t/n/a`。导致 `_resolveOffline` 里 `find(b=>b.t==='cue')` 返回 undefined 崩溃；AI `chooseShot` 找不到母球只能盲打兜底。

### 修复
- `renderer.js`：补 import `POCKET_R`；`drawBall` 用 `b.n ?? b.number`、`b.color || BALL_COLORS[num]` 兼容两种形状。
- `shared/physics.js` `createBalls()`：给物理球加 `t/n` 别名（`t=type, n=number`），客户端渲染/AI/规则无需区分形状。

### 自检工具沉淀（test/）
- `_browser_env.mjs`：可复用浏览器 stub（严格 canvas + 最小 DOM + rAF 队列 + pump + localStorage）。
- `browser_harness.mjs`：离线人机全流程。
- `browser_harness2.mjs`：触屏输入→瞄准→出杆、双人换手、瞄准辅助线 raycast、在线客户端流程。
- 经验：Node 端物理/规则测试覆盖不到「浏览器画布/模块解析/球字段形状」；客户端自检要用 DOM/canvas stub 复刻真实执行路径。

## 下午：全方位补齐功能

### 新增能力
- **到库犯规**：physics 事件新增 `cushionAfterContact`（首碰球之后才有球到库才计数）；rules 增加「未进球且首碰后无球到库 → 犯规」。
- **自由球(ball-in-hand)**：犯规 → `state.ballInHand={player}`，母球入手(inactive)；`physics.placeCue()` 落点(限台内+防重叠)。离线本地拖摆；在线发 `{t:'place',x,y}`，服务端校验后摆放并广播。客户端 input 增加摆放模式(幽灵母球)，AI 自动摆位。
- **再来一局**：结算遮罩按钮；离线 `startOffline` 复位；在线 `{t:'rematch'}`，服务端双方 ready 后 `start()` 重开。
- **断线重连**：连接带 `playerId`(localStorage 持久化)；服务端每座记 `seatPid`，掉线进 30s 宽限期不清房间、模拟定时器不停(广播跳空位)，同 pid 重连 `tryReconnect` 复位座位并回 `reconnected`+当前快照。**坑**：迟到的旧连接 close 会覆盖重连者 → onDisconnect 加 `players[seat]!==conn` 守卫 + tryReconnect 失效旧连接(cur.pid=-1)。
- **在线插值**：客户端 `snapBuf` 存(到达时刻,快照)，按 `now-110ms` 在两帧间插值球位置；turn/phase 等标量取最新快照。
- **UI**：力度条、自由球幽灵母球、静音开关(localStorage)、结算/掉线遮罩、轮次提示含「自由球/拖摆母球」。

### 测试沉淀
