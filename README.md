# 掌上台球 · 8 球（移动端横屏）

一个纯前端 + Node 服务端的移动端横屏 8 球台球游戏，支持：

- **离线 · 人机对战**（启发式 AI：会走位、会打安全球；可选**简单/普通/困难**三档难度）
- **离线 · 双人对战**（同屏热座）
- **在线 · 实时对战**（创建/加入房间，或**快速匹配**随机对手；两人联网对战）

服务端采用 **权威模拟（authoritative server）+ 状态快照广播** 的架构（参考 gandengyang 的 WebSocket 方案）：
物理与规则判定全部在服务端运行，客户端只发送「击球意图（角度 + 力度）」并渲染服务端下发的状态，
避免作弊与两端不同步。整套实现 **零运行时依赖**（WebSocket 握手与帧编解码用 Node 内置能力自研），
克隆即可 `node server/index.js` 直接跑。

## 运行

```bash
cd billiards
npm start            # 等价于 node server/index.js
# 默认 http://localhost:8080
```

- **手机访问**：把电脑和手机连同一 Wi-Fi，手机浏览器打开 `http://<电脑局域网IP>:8080`
  （如 `http://192.168.1.20:8080`，IP 用 `ifconfig` / `ipconfig` 查看）。
- **在线对战**：可「创建房间」得 4 位房号给对方加入，或「快速匹配」自动配对手；断线 30s 内自动重连续位。
- 在线战绩按匿名 ID 持久化（服务端 `server/data.json`），结算时显示。

## 操作（移动端横屏）

- 按住屏幕，**向母球反方向拉动**蓄力：拉得越远力度越大，松手发射；底部显示力度条。
- 人机模式下先选 **AI 难度（简单/普通/困难）** 再开局（会记住上次选择）。
- 瞄准时显示虚线辅助 + 幽灵球（预测首次碰撞点）与预计进球方向。
- **自由球**：犯规后对手需先**拖动幽灵母球**摆放后才可出杆；**开球犯规限开球区（开球线左侧）**，其余犯规可摆全台（界面会显示开球区阴影与开球线）。
- HUD 右上角可静音/取消静音（本地记忆）。
- 横屏体验最佳；竖屏会提示旋转手机。

## 物理与规则要点

- 固定步长 `1/240s` 子步积分，保证确定性；服务端按 60Hz 推进并向客户端广播快照。
- 等质量弹性碰撞、库边反弹、滚动指数阻尼、6 袋口捕获。
- 八球规则：开放球台首杆合法进球分配组别；需先清完本组 7 颗再打 8 号；
  未清台打进 8 号 / 8 号伴随犯规 → 判负；**未进球且首碰后无球到库 → 犯规**；
  **犯规后对手获得自由球**（开球犯规限开球区）；母球进袋同样入手。
- AI：进球时按「难度 + 母球走位 + 洗袋风险 + 下一目标可及性」选杆；无球可进时打**安全球**（轻力碰本组球、把母球与目标送离袋口）；三档难度调节瞄准抖动/走位权重/洗袋规避/选杆随机度。
- AI **前瞻**：对候选杆**克隆球局真实物理仿真到静止**，评估「是否洗袋、下一杆还有没有可进之球、能否顺势收 8」再选杆；前瞻候选数随难度提升（easy 不前瞻、normal 3 杆、hard 6 杆），实现真正的**多杆走位/续杆**。
- 在线：客户端按 ~110ms 延迟在两帧快照间插值；断线 30s 内按 playerId 重连续位；结算后可再来一局。
- 服务端健壮性：长期未配对的房间 10 分钟过期清理；优雅停机（SIGINT/SIGTERM）会通知在线对局。
- 手感参数（力度、阻尼、弹性、袋口大小）全部集中在 `shared/constants.js`，可按需微调。

## 已知简化（后续可扩展）

- AI 前瞻为 1 杆深度（仿真本杆后续杆评估），未做递归多杆搜索；获得自由球时由 AI 自动摆位。
- 在线匹配目前仅 1v1 队列；房间为内存态（战绩持久化到 `server/data.json`，房间不跨重启持久化，但有 10 分钟未配对过期清理与优雅停机通知）。
- 未做斯诺克式握手/比分盘等进阶规则。
